# Сайт школы кино и театра «ШКИТ»

Статический сайт: HTML + CSS + JavaScript. Никакой сборки, npm и зависимостей —
распаковал и открыл. Всё, что нужно, лежит в этой папке.

---

## Как посмотреть на своём компьютере

### Способ 1 — локальный сервер (рекомендуется)

Так страница ведёт себя ровно как на боевом хостинге. Нужен установленный Python:

```bash
python -m http.server 5173
```

Запускать из этой папки. Дальше открыть в браузере: <http://localhost:5173>

Остановить — `Ctrl+C`.

Если Python нет, подойдёт расширение **Live Server** для VS Code:
правый клик по `index.html` → «Open with Live Server».

### Способ 2 — просто открыть файл

Двойной клик по `index.html`. Сборки и сервера сайту не требуется, все пути
относительные — страница откроется и будет работать. Но проверять лучше
способом 1: именно так сайт увидят посетители.

> Интернет нужен для двух вещей: шрифт Montserrat (Google Fonts) и карта
> Яндекса в разделе «Контакты». Без сети сайт откроется, но шрифт будет
> системный, а вместо карты — пустая рамка. Остальное работает офлайн.

## Как выложить на хостинг

Загрузить **содержимое** этой папки (не саму папку) в корень сайта — туда,
где должен лежать `index.html`. Подойдёт любой обычный хостинг, GitHub Pages,
Netlify, Vercel, Timeweb, Beget — что угодно, что отдаёт статические файлы.
Ни PHP, ни Node.js, ни база данных не нужны.

После выкладки проверить, что открывается `https://ваш-домен/` и
`https://ваш-домен/policy.html`.

## ⚠️ Важно перед запуском в бой

### 1. Форма заявок сейчас в демо-режиме

Форма проверяет поля и показывает «Готово!», но **никуда ничего не отправляет**.
Чтобы заявки приходили в Telegram, нужно вписать два значения
в начало `assets/js/main.js` (строки 25–26):

```js
var TG_TOKEN = '';     // токен бота от @BotFather
var TG_CHAT_ID = '';   // id чата, куда слать заявки
```

Как их получить — подробная инструкция в комментарии прямо над этими строками.

Пока поля пустые, посетитель видит «Администратор скоро свяжется с вами»,
а заявка теряется. **Не выкладывайте сайт в таком виде.**

Токен виден всем в исходном коде страницы — заводите отдельного бота только
под заявки и не давайте ему доступ к другим чатам. Если такой вариант
не устраивает, нужен серверный обработчик формы.

### 2. Дублирование заявок на почту не сделано

Отправить письмо из браузера без сервера нельзя. Сейчас канал один — Telegram.

### 3. Афиша заполнена примерами

Три события в разделе «Афиша» — с выдуманными датами, а кнопки «Купить билет»
ведут на общий список Timepad, а не на конкретное событие. Перед запуском
заменить на реальные (в `index.html`, блок `<!-- 11. АФИША -->`).

### 4. Домен

В `index.html`, `sitemap.xml` и `robots.txt` прописан `https://shkit.ru/`.
Если домен другой — поправить там же (canonical, og:url, og:image, sitemap).
